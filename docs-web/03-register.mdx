## 完成账号验证

注册后进入微信小程序简幻欢，准确无误地输入您的简幻欢账号，然后支付一元即可绑定微信。

绑定后，每日从小程序签到即可免费长期使用服务器！[如何签到？](/web/easy_to_use)

:::tip[示例]

如您在官网注册时**账号**填写为 `user114514` ，则在微信小程序绑定账号时，填写的用户名也是 `user114514` 。
:::
