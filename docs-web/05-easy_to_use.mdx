# 如何长期免费使用

## 教程
+ 首次注册并认证后，每天仅需进入微信小程序简幻欢，点击签到，再点击开始签到，正确答题后即可。

:::tip[注意]

签到问题内容源自官网/文档，部分常识问题可使用搜索引擎搜索！你可以仔细寻找或通过文档搜索关键词功能找到答案，这也有助于您更好了解本项目！

签到答题机会与您目前的积分数量有关，请仔细审题后回答！

如您认为签到问题不合理，请前往 QQ 群 465468467，主动联系管理员，进行反馈！
:::

您可以通过多种方式获得更多积分，包括在官方交流群中活跃、推荐等。请注意，若您无法通过观看广告获得积分，**是微信限制的，与简幻欢无关**。

:::danger[警告]

您的积分若超过一定数值，将会无法签到。（当前该上限为 400，即积分超过 400 时候，无法签到；该上限随时可能发生变动，请以官方为准。）

此限制仅影响签到，其它渠道获得的积分不受该机制影响！

同时如您进行一些恶意行为，也将无法进行手动签到操作，详见：[【账号管理】您需要注意的机制](https://www.yuque.com/simpfox/simpdoc/mechanism#tAfNf)
:::
