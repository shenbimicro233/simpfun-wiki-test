# 【MCJE】服务端文件结构

:::info[提示]

此文档为介绍服务端预设的文件结构，即各个文件夹及其说明。

在简幻欢中，默认条件下，运行服务器的根目录为 `/home/container` ，下文提到的任何文件及结构，都应该在此文件夹内。

若有不精确或不完备的地方，欢迎指正及补漏。

:::

---

## Vanilla(原版)端
首先，让我们从最基础的Vanilla(原版)端开始说起。

![Vanilla 原版端根目录文件结构](/img/pages/mcje/mcje-server_files-1.png)

_这是Vanilla 1.20.2的服务端文件(仅展示根目录下的)。_

| 文件或文件夹 | 说明 |
| --- | --- |
| libraries | 存储游戏所需的Java库。如果你不知道里头都是啥不要去动！ |
| logs | 这是服务端的日志文件夹，用于存储服务端的运行日志。 |
| versions | 存储游戏的各个版本。每个版本文件夹中包含了该版本的Minecraft服务端程序及其相应的依赖项。 |
| world | 这是服务端的世界文件夹，用于存储服务端生成和加载的世界数据。   此文件夹名称可以在[server.properties](/mcje/server_properties)内的level-name一项修改 |
| banned-ips.json | 记录被封禁的IP地址。 |
| banned-players.json | 记录被封禁的玩家的UUID（唯一标识符）。 |
| eula.txt | 这是服务端的许可协议文件，用于确认用户同意遵守[Minecraft的最终用户许可协议（EULA）](https://www.minecraft.net/zh-hans/eula)。 |
| ops.json | 记录被授予操作员权限的玩家信息。   ops.json中存储的是玩家的UUID，而不是他们的用户名。 |
| server-1.20.2.jar | 这是服务端的主程序，用于启动和运行服务端（核心文件名你可以随便改, 改完记得在启动文件中修改启动参数）。 |
| server.properties | 这是服务端的配置文件，用于设置服务端的各种属性。[有关server.properties的详细解释](/mcje/server_properties) |
| usercache.json | 用于缓存玩家的UUID（唯一标识符）和用户名的映射关系。这个文件主要用于加速玩家登录过程。   需要注意的是，此文件不会存储玩家的数据。 |
| whitelist.json | 记录被允许连接到服务器的玩家列表。   此文件包含了被允许连接的玩家的UUID和用户名。 |

```text
Vanilla1.20.2/
├── libraries/               # 存储游戏所需的Java库
├── logs/                    # 服务端的日志文件夹
├── versions/                # 存储游戏的各个版本
├── world/                   # 服务端的世界文件夹
├── banned-ips.json          # 记录被封禁的IP地址
├── banned-players.json      # 记录被封禁的玩家的UUID
├── eula.txt                 # 服务端的许可协议文件
├── ops.json                 # 记录被授予操作员权限的玩家信息
├── server-1.20.2.jar        # 服务端的主程序
├── server.properties        # 服务端的配置文件
├── usercache.json           # 缓存玩家的UUID和用户名的映射关系
└── whitelist.json           # 记录被允许连接到服务器的玩家列表
```

_碎碎念：关于logs文件夹，它会存储服务器每次运行时的控制台输出并以txt文档保存，命名为服务器启动时间。感觉没必要为这个文件夹单开一个文档，所以在这说了。_

## Bukkit系插件端
Bukkit系端的各种分支比较多，此处挑两个比较有代表性的服务端来说。

### Spigot端
作为Paper的上游，这个端我认为还是需要拉出来说下的。

![Spigot 端根目录文件结构](/img/pages/mcje/mcje-server_files-2.png)

_这是Spigot 1.20.4的服务端文件(仅展示根目录下的)。_

与Vanilla端不同的地方如下所示（斜体表示不重要）：

| 文件或文件夹 | 说明 |
| --- | --- |
| bundler | Spigot端将Vanilla端下的libraries和versions两个文件夹的东西都合并到了这个文件夹内。 |
| plugins | 存放插件本体以及插件配置、数据等的文件夹。插件本体直接放入此文件夹即可。 |
| world | 在**所有Bukkit系服务端**内，世界存档**被拆成了三个文件夹**。   此文件夹存储的是主世界数据和玩家数据。   同时，[server.properties](/mcje/server_properties) 内的level-name的值会被同时应用在三个世界上面，即同时替换world字符。 |
| world_nether | 存放下界(地狱)数据。 |
| world_the_end | 存放末地数据。 |
| bukkit.yml | Bukkit系服务端的配置文件之一，用于配置一些基本的服务器设置。   所有CraftBukkit的分支都有此配置文件。 |
| _commands.yml_ | 一个配置文件，其中包含 CraftBukkit 服务器的自定义别名和命令方块覆盖。   命令方块覆盖系统提供了一种快速简便的方法，可以强制服务器将Mojang提供的命令（而不是Bukkit中内置的命令）用于命令方块，而所有其他命令保持不变。   而别名系统本质上使高级用户服务器管理员能够定义自定义命令并强制将特定版本的命令用于默认命令。   _PS：正常情况下你大概率用不到，甚至这东西都是去_[互联网档案馆](https://web.archive.org/web/20160325102040/http://wiki.bukkit.org/Commands.yml)_查的资料。_ |
| _help.yml_ | 这是Bukkit的帮助配置文件。   默认情况下，您不需要修改此文件。所有插件命令的帮助主题由插件自动提供。   _PS：正常情况下你大概率也用不到，因为现在的插件都会提供对应的帮助。_ |
| _permissions.yml_ | 用于定义玩家和用户组的权限。这个文件通常用于配置LuckPerms插件的权限设置。   _PS：花瓶一样的东西，当个摆设就好。_ |
| spigot.yml | Spigot服务端软件的配置文件之一，用于配置一些与服务器性能和行为相关的设置。   从Spigot分支出的服务端均有此文件。 |

```text
MinecraftServer/
├── bundler/                 # 合并了Vanilla端的libraries和versions文件夹内容
├── logs/                    # 服务端的日志文件夹
├── plugins/                 # 存放插件本体以及插件配置、数据等的文件夹
├── world/                   # 存储主世界数据和玩家数据
├── world_nether/            # 存放下界(地狱)数据
├── world_the_end/           # 存放末地数据
├── banned_ips.json          # 记录被封禁的IP地址
├── banned_players.json      # 记录被封禁的玩家的UUID
├── bukkit.yml               # Bukkit系服务端的配置文件之一
├── commands.yml             # 包含自定义别名和命令方块覆盖的配置文件
*├── eula.txt                 # 服务端的许可协议文件*
*├── help.yml                 # Bukkit的帮助配置文件*
├── ops.json                 # 记录被授予操作员权限的玩家信息
*├── permissions.yml          # 定义玩家和用户组权限的文件*
├── server.properties        # 服务端的配置文件
├── spigot.yml               # Spigot服务端软件的配置文件之一
├── spigot-1.20.4.jar        # 服务端的主程序
*├── start.bat                # 启动脚本*
├── usercache.json           # 缓存玩家的UUID和用户名的映射关系
└── whitelist.json           # 记录被允许连接到服务器的玩家列表
```

![Fabric 端根目录文件结构](/img/pages/mcje/mcje-server_files-4.png)

### Forge(1.17.1+)
此部分为1.17.1及更高版本的Forge服务端。

![Forge 1.20.1 端根目录文件结构](/img/pages/mcje/mcje-server_files-5.png)

_这是1.20.1 - Forge 47.1.43的服务端文件(仅展示根目录下的)。_

与Vanilla端不同的地方如下所示（斜体表示不重要）：

| 文件或文件夹 | 说明 |
| --- | --- |
| config | 存储FML和各个模组(mod)的配置文件的目录。 |
| defaultconfigs | 通常包含了模组(mod)的默认配置文件。这些文件是模组作者提供的初始配置，用于确保模组在首次安装时有一个合理的默认设置。 |
| mods | 存放mod本体的文件夹。 |
| world | **与Vanilla端保持一致。** |
| _user_jvm_args.txt_ | Forge服务端构建时生成的一个完全没有用的文件。 |

需要注意的是，1.17.1+版本的Forge服务端你在根目录下是找不到Forge核心与原版核心的。其启动命令应如下所示：

Linux：

```bash
${openjdk17} -server -Xms1024m -Xmx4096M @libraries/net/minecraftforge/forge/1.20.1-47.1.43/unix_args.txt "$@" -nogui
```

Windows：

```shell
java -server -Xms1024m -Xmx4096M @libraries/net/minecraftforge/forge/1.20.1-47.1.43/win_args.txt %* -nogui
```

### Forge(1.16.5-)
此部分为1.16.5及更低版本的Forge服务端。

_这是1.16.5 - Forge 36.2.39的服务端文件__(仅展示根目录下的)。_

与Vanilla端不同的地方如下所示（斜体表示不重要）：

| 文件或文件夹 | 说明 |
| --- | --- |
| config | 存储FML和各个模组(mod)的配置文件的目录。 |
| defaultconfigs | 通常包含了模组(mod)的默认配置文件。这些文件是模组作者提供的初始配置，用于确保模组在首次安装时有一个合理的默认设置。 |
| mods | 存放mod本体的文件夹。 |
| world | **与Vanilla端保持一致。** |

### NeoForge
与1.17.1+版本的Forge服务端一致，在根目录下是找不到NeoForge核心与原版核心的。由于更改了项目名称，其启动命令应如下所示：

```bash
## 1.20.1
${openjdk17} -server -Xms1024M -Xmx${maxmem}M  @libraries/net/neoforged/forge/1.20.1-47.1.106/unix_args.txt "$@" -nogui
## 1.20.2+
${openjdk21} -server -Xms1024m -Xmx${maxmem}M @libraries/net/neoforged/neoforge/20.6.115/unix_args.txt "$@" -nogui
```
